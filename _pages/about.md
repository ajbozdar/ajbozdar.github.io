## hi,
You are on Abdul-Jabbar Bozdar's personal website. I am a computer programmer writing reliable, secure, and performant code. 

My hobbies are finding new technologies, reading non-fiction books, and writing about programming. When not doing any of the above, I listen violin and do kata in the C language.

My high school teacher introduced me to C programming. My father had [a Fox Pro book](https://en.wikipedia.org/wiki/FoxPro) then, which he used as a reference at work. The book in early 2000 drove me crazy.

I was electronics engineering major during undergraduate studies. I learned a lot of mathematics and many programming paradigms. As an electronics student, hardware programming was crucial and that meant to have a high understanding of the C and Assembly languages. I gradually leaned toward software development and went on developing applications for the masses.

I had an interest in computer communications and Cisco networking too, but now distributed web applications fill up the gap. I am fond of developing web applications in Ruby on Rails. New programming languages, compilers, and interpreters fascinate me a lot.

## About Desktop Computing
The Unix systems are my favourite. I have been using Unix like operating systems since 2006. Debian runs on both work and home computers. I would say, these two are first class operating systems offering excellent features and stability.

### My First Unix Like Operating System
Although my first ever Unix like operating system was Ubuntu, Debian gave me a better opportunity to understand system software. As my understanding progressed about systems engineering, I gradually inclined towards standard monolithic system software. Therefore, I made into the BSD world. This made computing great again for me.

### About FreeBSD
The way it distributes the resources doesn't make me feel, like, there is a desktop environment glued on top of a (micro)kernel. FreeBSD's kernel architecture is monolithic and cohesive. It favours the stability and performance.

## About The Website  
Jekyll is the engine behind this website which is built on top of the Ruby stack. It is a static site generator and really a fantastic one out there. I prefer Ruby for web programming over any other language. 

I designed my website using an [archived theme, Tale](https://github.com/chesterhow/tale/). I used it as a base and extended it with some nice markup. I use [GitLab](https://gitlab.com/imbozdar)'s CI/CD pipelines to push my site to Vercel.

## Simple Privacy Policy

I made my website using plain HTML and CSS. The website is using a static site generator, but it also makes the use of some external services for searching, commenting, and caching. I developed some of the backend features myself. If you enter some queries to search for something, it will return specific results. You may post comments as well. I do not collect any data personally except the email addresses of the users and the names they provide when they choose to subscribe to the post notifications, comment on posts, or subscribe to the future posts.

<div class = "note yellownote">
  <p>The internet is a public place, and it can never be 100% secure or private at any given time for anybody.</p>
</div>

As a technologist, I made a choice to learn more about how web traffic flows in and out. This helps me to improve my writing skills. For this, I use a few tools to understand the web traffic flow. I only use a chunk of data, or you may say some unidentifiable data per day, to analyse web traffic on my website. I do all this on my computer using a spreadsheet. I use [Ckicy Analytics software](https://clicky.com/101464241){:title="analytics provider"} to learn about website traffic. I use Clicky's default settings that comply with GDPR. You may refer to [Clicky's privacy policy](https://clicky.com/help/faq/privacy) for further details.

Besides the above, I also use Fastly's CDN service and the Amazon Associate program which might leave their own cookies in your browser. I do not store any of them, and their cookies are beyond my control. I set up the social buttons myself on the blog posts, and they do not have any tracking strings attached.

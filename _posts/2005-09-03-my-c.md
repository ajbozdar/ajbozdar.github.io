<span class="dropcap">T</span>oday, at school, we learned about the computer programming in class. We used the C language to write our first program. It is a high level and systems programming language.

We can manipulate a computer systems using the C language. Using C, we can also program hardware. I liked the blue screen of The Turbo C++. It is an integrated development environment, IDE, and has a built-in debugger which helps with minor mistakes in code.

## My First C Program
Let's talk about what I did today in the class. When finished with instructions, we wrote some code as our instructor told us. I am copying here the same code, and explain how it works.

{% highlight c linenos %}
// My first C program

#include <stdio.h>
#include <conio.h>
void main(void)
{
  clrscr();
  printf("This is my first C program.");
}
{% endhighlight %}

## Comments
The first instruction in the program `// My first C program` is a comment. It does not execute. It asks C compiler to ignore whatever comes after the two `//` forward slashes.

## Pre-processing Directives
The second and third line of the code are two pre-processing directives, or you may say external libraries as header files. What does it mean? It means these two directives will use the information in the header files. You can identify the header files with a `.h` extension. The first one `stdio.h` borrows all the standard input output programs and "includes" them in my program. The second one `conio.h` is also an input/output library and helps to clear the screen.

## The Main Function
The next line `void main(void)` is the main function of the program. All the executable code begins from there. In C programming, we must specify one function at least. We have one function now, `main`. All functions must return some computed results. As we are not computing anything, our function does not need to return anything. Thus, we wrote `void` before the `main`. Now it won't return any computations. The second `void` in parentheses asks function to not worry about any inputs. We also call them arguments.

## Console Input/Output
Now we have `clrscr();` which is also a function, and it helps to clean the Windows CMD console. It clears the console screen and jumps to line 1. It is defined in `<conio.h>` header.

## Standard Input Output
The `printf();` function comes from `<stdio.h>` and helps us to print some strings of characters in the quotation marks. 

This was my first ever program in the C language. I'll share more as I continue learning programming. This is so good.

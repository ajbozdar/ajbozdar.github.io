<span class="dropcap">I</span> have never waited this eagerly for an Ubuntu update as much I did for 18.04. This is all because Gnome DE has made its return to Ubuntu. The Unity is gone for good.

Someone might disagree, but the Gnome team has done more damage up till now than a service. Nearly everything breaks when they release their next version. Now, can someone tell me when they'll release their 4.0 that is consistent with extension developers?

The Gnome tweak tools app is handy for making changes that don’t break the desktop environment, but it has limited scope. Overall, I am happy for Gnome that it made its way back to Ubuntu. Gnome has the potential to become a competitive desktop environment against the  Macintosh operating system.

In the cover image, you can see that Ubuntu has also reverted back the toolbar buttons to the right side. I still do not understand this logic. First, you try to look like Macintosh, then you decide to become Windows. As far as I know, the right side is better. Left has nothing to do with the user experience.

I am gnomic. I depend on the Gnome software. It does me a great favour while locating my files and folders without getting in my way. I have [tried KDE]({{site.url}}/kubuntu/) and Cinnamon, but they are a mess when it comes to the desktop search.

I would say, as Unity is gone, most of the user experience will stay the same. Ubuntu will keep mouslding Gnome to keep the user interface look consistent.

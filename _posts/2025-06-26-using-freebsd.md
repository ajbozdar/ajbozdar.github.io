<span class="dropcap">M</span>y computer is using FreeBSD 
because I am upgrading my Unix skills. FreeBSD is the only
OS that would be helpful now, instead of being full of hell.

A few days back, my younger brother came to visit me. He looked at my work and
suddenly said, "your computer is slow". I said this is the time; I got to get rid
of this OS. I already had some familiarity with FreeBSD. Likewise, I first tested and
tried it back in 2014. Later, I used it in the cloud to host a couple of websites.
The experience was fantastic.  
 
I avoided using FreeBSD on desktop for all the Unix reasons not supporting
different hardware. But I was already convinced a decade ago that FreeBSD's
Unix traits are not as same as we experience using mainstream Unix-like distributions.

Now, the good thing is that I have already installed FreeBSD 14.2 about 10 days
ago. The installation on my Lenovo IdeaPad S400 was smooth. It's running like a
charm.  I haven't experienced any hardware incompatibility issues yet. I can feel the true power
of a Unix operating system. The way FreeBSD installs packages, syncs with repositories, and moves files over multiple SSDs is something I missed on Fedora.

This is all about the way a BSD operating system is designed from the
ground up to finishing. Its monolithic kernel isn't decoupled from the userland.
I will write more about the technical supremacy of the operating system, and how
it perfectly aligns with the true Unix philosophy.

For now, I would  prefer to go and finish their [massive handbook](https://docs.freebsd.org/en/books/handbook) once for all. I hope this will help to eliminate all the gaps as a desktop user this time.

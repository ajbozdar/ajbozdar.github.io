<span class="dropcap">T</span>wo weeks ago, I learned about the Fedora Test Week in [a post published in the Fedora magazine](https://fedoramagazine.org/contribute-at-the-fedora-41-i18n-and-tuned-test-week/). As a programmer, I have written unit tests for my code. But, I never tested another programmer's implementation before.

Fedora is introducing **Tuned** as a default power profile daemon in Fedora 41, so they needed to test the implementation before the release. It was a simple task and took me as little time as spinning up the Fedora 41 pre-release workstation edition in VM.

The [wiki page](https://fedoraproject.org/wiki/Test_Day:2024-09-09_Fedora_41_Tuned) had everything for me to begin except how to test. It was missing, and I don't remember exactly how I found out [QA test case page](https://fedoraproject.org/wiki/QA:Testcase_tuned). Perhaps it was the mailing list, but I don't remember exactly while writing this post.

On the QA test page, all the steps were given. The only thing I had to check was if my results matched the expected results. Easy peasy! 🤜 🤛

![fedora pre-release installation]({{site.url }}/assets/images/fedora-pre-release-tuned-test-day-installation.webp){:loading="lazy" width="800" height="auto"}_Fedora 41 Pre-release Edition Installation in Progress_

As soon as Fedora 41 installation finished in VM, I went on testing each test case.

## The First Case
In the first case, I needed to swap the `power-profile-daemon` with `tuned-ppd`. As I was using Fedora 41, it was already enabled. Thus, this did not apply in my case.

## The Second Case
In the second case, I launched the Gnome Control Centre and selected all the power profiles one by one. I made sure that the correct power mode shows up in the top right corner of the Gnome DE, as shown in the following screenshot.

![fedora tuned test case power mode selection]({{site.url}}/assets/images/fedora-tuned-test-case-power-mode-selection.webp){:loading="lazy" width="800" height="auto"}_Power Mode Selection Tested_

## The Third Case
Here came the command line. 😏 I ran `tuned-adm active` command, and it showed me the active power profile. I matched it with the profile selected in the top right corner. Both scenarios matched and our test passed.

![fedora tuned ppd test on command line]({{site.url}}/assets/images/fedora-tuned-ppd-test-on-command-line.webp){:loading="lazy" width="800" height="auto"}_tuned-adm command output matches the graphical presentation_

## The Fourth Case
In our final case, I verified power profile name mapping. In the following screenshot, you can see that the correct power profile is shown. The tuned-ppd configs are in `/etc/tuned/ppd.conf` file.

![fedora tuned power profile name mapping verified]({{site.url}}/assets/images/fedora-tuned-power-profile-name-mapping-verified.webp){:loading="lazy" width="800" height="auto"}_Power profile name is correct in all scenarios._

I also tested stability of power profiles while changing the power profiles multiple times in a short time span. I verified that the profile name and working remain same. All was okay. Later than, I added my comments on [the results page](https://testdays.fedoraproject.org/events/196).

This was one of the fantastic FOSS activities for me. I am exploring ways to contribute more to Fedora. There will certainly be a project where my skills will be useful for the community.

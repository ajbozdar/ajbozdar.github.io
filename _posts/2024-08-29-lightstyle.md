<span class="dropcap">T</span>he day before yesterday, I created a new user on my computer to test some functionality of the Wayland desktop. I did not need to change any settings, so I went straight into the file manager. I was not expecting that Gnome would log me into light mode as a new user, but it did. 

Then I saw the [greatness of light]({{site.url}}/screenshot-saturday/), and this is the story of that cosmic journey. 🌞

![Can you believe this is the Gnome's default light mode]({{site.url}}/images/gnome-light-mode.webp){:loading="lazy" widht="800" height="auto"}_When you log into the Gnome, this is the light it returns. 🙄_

## The Rein of Dark Age

In late April 2021, Canonical released Ubuntu 21.04 and shipped the Gnome desktop environment with a dark mode. The appearance looked fantastic. There were also some accent colors as much as I remember, but altogether it was nice. I changed the default style to dark, and it unleashed the curse. 😱

I switched to Fedora last year in May, so I could use the latest Gnome software and feel more Gnomic. I can recall it like yesterday that as soon as Fedora 38 installation finished, I first clicked on the dark style in the system properties and began setting up the operating system later.

![Can you believe this is the Gnome's default light mode]({{site.url}}/images/gnome-desktop-light-style.webp){:loading="lazy" width="800" height="auto"}_Click that thing and feel the rein of darkness._

After that, I changed all applications including on my phone to dark mode. The light style became a thing of the past. I had completely forgotten how does the light interface even looks alike. The dark mode became my new normal user interface at home, office, and everywhere else.

This was how the curse of darkness trumped over my computing needs. 👺

## The Return of Heavenly Light

I didn't need any changes for my new user. Although it was temporary, it was going to shade the light. When I opened the file manager, I was frozen. An icy feeling shivered through my spine and uttered, what's that! Who installed this Iceland on my computer? "I whispered to myself."

![Can you believe this is the Gnome's default light mode]({{site.url}}/images/gnome-file-manager-nautilus-light-style.webp){:loading="lazy" width="800" height="auto"}_Nautilus: Gnome's Forever File Manager_

To me this new light style was remarkable, and the bold icons looked nice too. Once I finished my work, I logged into my environment and expanded the system properties to deselect the dark style in time. I did not find any difficulty changing any application software as most of the applications, like browsers, text editor, and <abbr title="Integrated Development Environment">IDEs</abbr>, were already running on system default. I changed the appearance of web apps that were running the dark themes like [fosstodon](https://fosstodon.org/@yabozdar).

![gnome text editor running light cobalt theme]({{site.url}}/images/gnome-text-editor-running-light-cobalt-theme.webp){:loading="lazy" width="800" height="auto"}_Gnome Text Editor Running Light Cobalt Theme_

After using the light mode for a couple of hours, I took a breath of freshness. The system felt lighter too and more attractive than the dark mode. This was the moment my computer nodded in yes to begin the journey of change from darkness to lightness for the sack of our mutual inner peace.

I went on changing the appearance of my phone and the room as well. My phone and all the apps are now running light themes. I also bought a new 20 watt white bulb to enlighten my work desk at home. It is shining like the sun on my desk right now. 💡

## The Final Touch
It would exaggerate if I say, I am in love with Gnome's icons design. In dark mode, I was using Colloid dark icons. Now, I am using [beaming Colloid](https://github.com/vinceliuice/Colloid-icon-theme)  light icons. These all things together made Fedora great again.

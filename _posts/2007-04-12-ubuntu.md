<span class="dropcap">I</span> got the CD last year by mail, but I am running it for the first time on my computer today. I am eager to learn everything about this new operating system. It is very different from Windows XP. Software engineers in Europe developed this operating system free for the human beings.

The operating system's name is Ubuntu. It is a Unix like system software. We also do
not need to pay for the license to use it on our computer. I won't see any blue screen
of death anymore (BSOD).

Ubuntu is a Unix like operating system. It only needs 256 MiB of RAM. I have 1.5 GiB on my
computer right now. I do not need any drivers to find here and there for my hardware.
Ubuntu installs all the drivers itself.

This has a powerful terminal. XP does not have it. XP catches viruses. Viruses cannot corrupt files on Ubuntu. My USB is safe now. What else do you want in this world? I feel happy, so happy!

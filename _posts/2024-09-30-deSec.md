<span class="dropcap">I </span> have been using deSec DNS service for two months. It's time that I should introduce my friends to [deSec.io](https://desec.io/). Actually, deSec is a free DNS hosting service for the masses to use. It takes pride in its security features and motivates users to enable <abbr title="Domain Name System Security Extensions">DNSSEC</abbr> for their domains. The service provides DNS hosting only and does it well.

## My First Impression
The first thing I observed was that the DNS information updated faster than any other service. As soon as I delegated name server details to registrar, my website propagated through the world wide web in no time. It was, like, changing the browser's tab. My website was online, and that was it. I remember when my first website took a day to come online in 2009. 🤦‍♂️

![desec dns hosting set-up wizard]({{site.url}}/images/desec-dns-hosting-set-up.webp){:loading="lazy" width="800" height="auto"}_deSEC set-up wizard_

## Domain Limit
Initially, my account had a limit to host only one domain. A few days back I wrote them to increase the domain limit to three, and I got it up to five folds in return. For now, I have two websites using their name servers. It's all going fasting. The DNS information for the second domain spread in a blink of an eye, and a few other records took less than 20 seconds to verify.

I found some users complaining about the domain limit on [deSec's forums](https://talk.desec.io/). But, there is an obvious question. Why give a free service without limits?

## Record Types
If you ask about record types, all the standard and modern types are available on deSEC. The interface is neat and clean. They also have first class support for Let's Encrypt certificates. What else they use free open source software to run deSEC. The system handles IPv6 without a lag. Users can enable 2FA on their accounts. 

![deSEC DNS record types](/images/desec-dns-hosting-record-types.webp){:loading="lazy" width="400" height="auto"}_deSEC DNS record types_

These all things make deSEC a pretty good DNS hosting service. Why not try it for your next project? If you like donating to <abbr title="free open source software">FOSS</abbr>, then consider giving [desec.io](https://desec.io/donate/).

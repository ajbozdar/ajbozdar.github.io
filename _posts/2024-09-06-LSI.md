<span class="dropcap">I</span> would say, Jekyll is fantastic. It works like a charm, and there are also not so many flaws in the system to generate a static site generator. Jekyll does what it is told to do. This is simply the best thing.

## Perfection is fiction.
While Jekyll works fantastic, it has a flaw. It is the build time that constantly increases. I had only nine pages and fifteen posts on my website, but the build time had reached 10.5 seconds already. What else, I haven't imported my [all blog posts]({{site.url}}/blog/) from previous websites yet. It would have been okay if it was the build time only, but the local development time increased too. In the last two weeks, it began annoying me while running `serve` command.

```shell
# Jekyll's local development command.
$   bundle exec jekyll serve --livereload
```

## What Increased Jekyll's Build Time?
I like related posts feature in blogs. So, I installed [classifier reborn](https://jekyll.github.io/classifier-reborn/lsi) gem as a Jekyll plugin to get a high quality related posts list. Classifier Reborn uses the Latent Semantic Indexer, LSI<sup>1</sup>, technique to identify similar posts using the document text. 

In a broad mathematical definition, LSI analyses my posts and produces a set of titles that are related to each other. It pulls the data while finding similar categories, tags, and text in a blog post.

Now, I was happy using the plugin. It began increasing the build time. I let it do so, because I wanted to see how far the build time goes. The day before yesterday, when I gave Jekyll `serve` command, and I turned to the browser to load my website. It did not load. I wondered, what could go wrong? I returned to the code editor and found that the Jekyll was still processing the command.

## Time To Reduce The Build Time
I realised it was enough testing my patience. I headed to [rubygems.org](https://rubygems.org/gems/narray/) and searched for `narray` and `linalg` gems. They both are numerical modules under Numo. Numo makes processing time faster and eases manipulation of numerical data.

> Numo is a set of Numerical Module gems for Ruby that provides a Ruby interface to LAPACKE.
>
> <cite>--According to the <a href="https://jekyll.github.io/classifier-reborn/">Classifier Reborn</a> website</cite>

## Installing LAPACKE and OpenBLAS on Fedora
Both gems need GSL<sup>2</sup> or LAPACKE<sup>3</sup> to work on any system. I already had GSL on my system, but it is not ruby friendly, and this doesn't bother me to abandon `ruby`. After all, I was happy that it is time to use LAPACKE.

It is fairly simple to install LAPACKE header and development files on [Fedora]({{site.url}}/about/#the-desktop-computing). Fedora installs [OpenBLAS](https://www.openblas.net/) libraries as dependencies for LAPCAKE. I ran the following command, and voilà!

```shell
$   sudo dnf install lapack
```
In case, you also need to install BLAS development files on Fedora. Use the following command. You can find all Fedora packages are listed on its [packages portal](https://packages.fedoraproject.org/pkgs/lapack/lapack/).

```shell
$   sudo dnf install blas-devel
```
## We are done.
Once finished, I ran the `serve` command again, there was it. A much reduced time to connect to browser. Classifier Reborn website might be claiming ten times faster analysis of the text, but it saved my time up to six times on the first run. The time to build the website went from 10.5 seconds to 1.7 seconds.

Now, the build time varies between 1.6 seconds to 2.1 seconds. I am happy with this outcome. Numo has limitations, so the build time will increase again. I do not have issues with build time as I build my website locally and push to [GitLab CI/CD]({{site.url}}/about/#about-the-website). Let's see how farther I go with this setup. I do not want to change my blogging work flow. Not before the year end, at least.

1. **LSA**: Latent semantic analysis pulls the documents that have words with similar meaning.
2. **GSL**: It is GNU Scientific Library to improve LSA of the documents.
3. **LAPACKE**: Linear Algebra PACKage.
